\# Phase 00 - Planning



The Planning phase establishes the technical foundation for the Enterprise SOC Lab. It defines the project scope, lab objectives, network architecture, software requirements, and implementation roadmap before infrastructure deployment begins.



\---



\## Phase Status



| Phase | Status | Progress |

|------|--------|----------|

| Planning | Complete | 100% |



\---



\## Phase Objectives



\- Define the mission and scope of the Enterprise SOC Lab

\- Establish the network architecture and IP addressing plan

\- Identify required operating systems, tools, and security platforms

\- Define technical and professional learning objectives

\- Create a structured implementation roadmap

\- Establish consistent documentation standards

\## Planned Environment



| Component | Role |

|-----------|------|

| VMware Workstation Pro | Virtualization platform |

| pfSense | Firewall, routing, and network segmentation |

| Windows Server 2022 | Active Directory and infrastructure services |

| Windows 11 Enterprise | Domain-joined management workstation |

| Ubuntu Server | Elastic Stack and Linux services |

| Kali Linux | Controlled attack simulation platform |

| Suricata | Network intrusion detection |

| Sysmon and Winlogbeat | Endpoint telemetry and log forwarding |
